# Simple Interest Calculator

## Description
This project contains a simple shell script that calculates simple interest based on the principal amount, annual rate of interest, and time period.

## Features
- Calculates simple interest
- Easy to use
- Written in Bash shell script

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Usage
Run the script using:

```bash
bash simple-interest.sh
```

Enter the required values when prompted:
- Principal amount
- Rate of interest
- Time period

The script will display the calculated simple interest.
